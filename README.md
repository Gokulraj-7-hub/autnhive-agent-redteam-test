# autnhive-agent-redteam-test

Purpose-built, non-production test agent for the **Autnhive Agentic AI Red Teaming Program**
(Com Olho program #459). This repository exists solely for authorized security testing of the
SAMI AI Agent scanner, per the program's rules of engagement. It contains a minimal LangGraph
agent plus benign instrumentation that reports back to a researcher-controlled endpoint to
evaluate the scanner's code-execution and outbound-network controls. No destructive behavior.
